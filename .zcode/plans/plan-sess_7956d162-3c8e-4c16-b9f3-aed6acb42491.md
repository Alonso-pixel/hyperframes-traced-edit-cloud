## Phase 1 — R2 bucket + API token
1. `npx wrangler login` (user clicks the browser OAuth once).
2. `npx wrangler r2 bucket create traced-edit`. If R2 isn't enabled on the account, the error says so → user enables R2 in dashboard (payment method on file; free tier 10 GB > 3.9 GB needed), then retry.
3. R2 S3 keys are **dashboard-only** (wrangler can't mint them). User: R2 → Manage API Tokens → Create API Token → *Object Read & Write*, scoped to bucket `traced-edit` → copy Access Key ID + Secret Access Key + Account ID, paste to me.
4. Write repo-root `.env` (git-ignored): `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET=traced-edit`.

## Phase 2 — Asset upload (runs in background while we do 3–5)
- `node sync.mjs --assets` in background (rclone sync, 3.9 GB — can take a while on your uplink). `node sync.mjs --check` for a dry-run report. Verify bucket object count/size afterwards (rclone ls or dashboard).

## Phase 3 — Upload Worker
- Generate once: `UPLOAD_HMAC_SECRET=$(openssl rand -hex 32)`; append to `.env` for reuse on Railway.
- `cd upload-worker` → `printf '%s' "$SECRET" | npx wrangler secret put UPLOAD_HMAC_SECRET` → `npx wrangler deploy` → capture `https://traced-edit-upload.<you>.workers.dev` → `curl -s -o /dev/null -w '%{http_code}'` it to confirm it responds.
- After Phase 5, optionally set Worker secrets `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` for the "uploaded" ping.
